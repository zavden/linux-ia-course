# C03 — minifind-plus (guiado)

## Objetivo
Extender minifind con opciones más cercanas a la utilidad real.

## Qué debe hacer
- `-name` con glob (`fnmatch`).
- `-type` (`f`, `d`, `l`).
- `-size`, `-maxdepth`, `-mindepth`.
- manejo de errores por ruta sin abortar búsqueda total.
- código de salida no-cero si hubo errores.

## Estado
Plantilla guiada (sin resolver completamente).
