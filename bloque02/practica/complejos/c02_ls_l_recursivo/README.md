# C02 — ls -l recursivo (guiado)

## Objetivo
Implementar un listado recursivo con metadatos legibles y robustez ante errores.

## Qué debe hacer
- Recorre árbol de directorios.
- Muestra tipo, permisos simbólicos, tamaño, mtime y nombre.
- Usa `lstat` para no desreferenciar symlinks por defecto.
- Continúa aunque encuentre rutas con error.

## Estado
Plantilla guiada (sin resolver completamente).
