# E03 — stdio vs syscalls

## Objetivo
Visualizar diferencia de enfoque entre I/O byte-a-byte con syscalls y con stdio.

## Qué hace
- Crea un archivo de prueba.
- Copia byte a byte con syscalls.
- Copia byte a byte con stdio.
- Imprime tiempos comparativos.

## Ejecutar
```bash
make run
make test
```
