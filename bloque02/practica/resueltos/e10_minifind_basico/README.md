# E10 — minifind básico resuelto

## Objetivo
Integrar recorrido recursivo + filtros de nombre/tipo/tamaño en una utilidad estilo `find`.

## Qué hace
- Uso: `./main [base] [-name X] [-type f|d|l] [-size Nc]`.
- Si no hay base, usa `.`.
- Recorre árbol recursivamente y aplica filtros.

## Ejecutar
```bash
make run
make test
```
