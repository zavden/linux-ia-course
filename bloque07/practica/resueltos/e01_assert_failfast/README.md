# E01 — assert y fail-fast

## Objetivo
Usar `assert` y validaciones explícitas para detectar estados inválidos temprano.

## Qué hace
- Valida rangos y divisiones seguras.
- Usa `assert` para invariantes internas.
- Devuelve errores controlados en entradas inválidas.

## Ejecutar
```bash
make run
make test
```
