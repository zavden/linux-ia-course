# E08 — dispatch table con punteros a función

## Objetivo
Reducir `if/else` largos usando tabla de comandos y funciones asociadas.

## Qué hace
- Declara tabla `nombre -> función`.
- Parsea comandos simples con dos operandos.
- Ejecuta operación o responde error si no existe.

## Ejecutar
```bash
make run
make test
```
