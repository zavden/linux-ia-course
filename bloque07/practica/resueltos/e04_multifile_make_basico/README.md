# E04 — proyecto multifile con Make

## Objetivo
Organizar código en varios módulos `.c/.h` y compilarlo como unidad con Make.

## Qué hace
- Separa operaciones matemáticas y formateo de texto.
- `main` consume APIs de ambos módulos.
- Valida integración y enlace correcto.

## Ejecutar
```bash
make run
make test
```
