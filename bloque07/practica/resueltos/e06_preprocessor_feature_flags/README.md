# E06 — feature flags por preprocesador

## Objetivo
Activar/desactivar rutas de código con `#ifdef` de forma controlada.

## Qué hace
- Define implementación base y ruta rápida opcional.
- Informa si `FAST_MODE` está activo.
- Verifica resultado funcional idéntico entre rutas.

## Ejecutar
```bash
make run
make test
```
