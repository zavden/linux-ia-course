# E04 — parser de ACL textual

## Objetivo
Comprender estructura de salidas ACL tipo `getfacl` parseando entradas relevantes.

## Qué hace
- Lee archivo de texto estilo ACL.
- Cuenta entradas `user`, `group` y `default`.
- Ignora comentarios y líneas vacías.

## Ejecutar
```bash
make run
make test
```
