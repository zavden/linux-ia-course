# E06 - validacion de entrada segura

## Objetivo
Aplicar validaciones estrictas para evitar que entradas mal formadas lleguen a la logica de negocio.

## Que hace
- Valida nombre de usuario por longitud y conjunto permitido de caracteres.
- Parsea puerto de red con conversion numerica estricta.
- Reporta estado de validacion para cada campo.

## Ejecutar
```bash
make run
make test
```
