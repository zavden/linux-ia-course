# E02 — optind y argumentos posicionales

## Objetivo
Entender cómo separar opciones de argumentos posicionales con `optind`.

## Qué hace
- Opción `-u` para convertir a mayúsculas.
- Soporta `--` para cortar el parseo de opciones.
- Procesa solo tokens posicionales finales.

## Ejecutar
```bash
make run
make test
```
