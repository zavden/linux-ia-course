# C03 — minicat-lite

## Objetivo
Construir una versión reducida de `cat` con semántica sólida de errores.

## Qué debe hacer
- Leer de archivos y de `stdin` cuando se pase `-` o no haya archivos.
- Soportar `-n` (numerar todas) y `-b` (numerar no vacías).
- Continuar con siguientes archivos aunque uno falle.
- Salir con código no-cero si hubo al menos un fallo.

## Estado
Plantilla guiada (no resuelto).

## Ejecutar
```bash
make run
```
