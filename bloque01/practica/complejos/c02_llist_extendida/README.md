# C02 — Lista genérica extendida

## Objetivo
Implementar una lista enlazada reusable con ownership configurable y API más completa.

## Qué debe hacer
- `push_front`, `push_back`, `pop_front`, `find`, `foreach`, `destroy_ex`.
- Mantener invariantes (`head`, `tail`, `size`) consistentes.
- Permitir liberar datos con callback (`free_fn`).

## Estado
Plantilla guiada (no resuelto).

## Ejecutar
```bash
make run
```
